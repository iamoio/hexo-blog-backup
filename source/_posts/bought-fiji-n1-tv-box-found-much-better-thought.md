				<blockquote>
  <p>“电视盒子哪家强？”</p>

  <p>“别问，问就是N1。”</p>

</blockquote>

<p>在某屎黄色论坛，隔三岔五就能看见以上对话。</p>

<p>家中奋战4年的小米盒子眼瞅着大限将至，于是我也买了一台。</p>

<h1 id="购买开箱">购买开箱</h1>

<p>由于去年斐讯“0元购”暴雷，其产品已经被主流电商全面封杀。</p>

<p>现在别说京东淘宝，就连闲鱼都ban了关键字。</p>

<p><strong>“主流平台既然没有，那上非主流的不就行了？”</strong></p>

<p>——于是年轻人第一次安装了<a href="https://www.pinduoduo.com/">拼多多</a>。</p>

<p>无愧于“2元路边摊”美名，拼多多上乱七八糟应有尽有，突出一个鱼龙混杂胆大包天。</p>

<p>斐讯N1也是各种“套餐”，售价50~150不等：</p>

<ul>
  <li>矿机转手，底价；</li>
  <li>刷好固件+T1遥控器的充新货，主流；</li>
  <li>全新未拆，不多。</li>
</ul>

<p>由于N1的<strong>本来用途是挖矿</strong>，而挖矿势必对硬件寿命造成影响，<strong>刷好机的充新货更是来源不明</strong>。</p>

<p>为了用着持久坚挺，我最后花了95，买了台全新未拆（自称）。</p>

<p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2heavhxj212w0pyx6p.jpg" alt=""></p>

<p>到手就发现这全新未拆（自称）的外壳包装堪称<strong>库存战损</strong>，拆开后果然连N1本体上也沾着手指印。</p>

<p>到底是“2元路边摊”。</p>

<p>不过机器sn码与外包一致，除了有俩指印并无其它使用痕迹，就连底部的“0元购兑换码”涂层也没刮。</p>

<p>——姑且就当是全新吧。</p>

<p><strong>“买都买了，还能咋办？”</strong></p>

<p>拆箱过程略，毕竟内容物只有：</p>

<ol>
  <li>本体x1；</li>
  <li>电源x1；</li>
  <li>说明书+废纸片。</li>
</ol>

<p>至于盒子本体，非常小巧，方方正正。</p>

<p>白色硬质塑料外壳，保障散热优秀并且耐操；</p>

<p>而顶盖由一整块亚克力玻璃点缀，更显简约精致。</p>

<p><strong>斐讯N1在电视盒子这个充满歪瓜裂枣的领域，就是毫无悬念的颜值担当。</strong></p>

<p>——<del>虽然它原本不是电视盒子。</del></p>

<p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2k0f9mqj212w0py1ky.jpg" alt=""></p>

<p>屁股接口丰富：</p>

<ol>
  <li>电源接口 x 1；</li>
  <li><strong>千兆网口</strong> x 1；</li>
  <li>HDMI x 1；</li>
  <li>USB x <strong>2</strong>；</li>
</ol>

<p><strong>放眼电视盒子界，有网口的比它缺USB；有USB的比它缺网口；啥都有的价格又比它多个零。</strong></p>

<p>君不见隔壁要价299的<a href="https://www.mi.com/mibox4/">小米广告盒子4</a>，不仅少接口，硬件（Amlogic S905L）还比这95包邮的斐讯N1（Amlogic S905D）残了一截。</p>

<p>也难怪某屎黄色论坛一提电视盒子，就是标配N1。</p>

<p>——<del>虽然它原本不是电视盒子。</del></p>

<h1 id="刷个机吧">刷个机吧</h1>

<h4 id="固件选择">固件选择</h4>

<p>必须注意的是，斐讯N1的盒子固件都是由斐讯官方固件修改而来。</p>

<p>——<strong>所以系统都是标准Android7.1.2，而非Android TV。</strong></p>

<p>主流固件有以下几种：</p>

<ul>
  <li>
    <p><a href="https://right.com.cn/forum/forum.php?mod=viewthread&amp;tid=338759">webpad固件</a>。</p>

    <p>基于官方固件 v2.32 版修改，是其它所有第三方固件的“爸爸”。</p>

    <p>自带root，不带root管理，内置乱七八糟一堆app，但可以删。</p>

    <p>流畅度一般。</p>
  </li>
  <li>
    <p><a href="http://www.yyfrom.com/cms/index.html">YYF固件</a>。</p>

    <p>基于webpad旧版固件（对应官方固件 v2.19 版）的精简修改+扩展版。</p>

    <p>自带root，自带root管理，移除了所有webpad固件内置垃圾app，加了很多实用功能，如语音控制/远程管理/bt下载之类。</p>

    <p>流畅度优于webpad固件。</p>
  </li>
  <li>
    <p><a href="https://www.right.com.cn/forum/thread-315889-1-1.html">Rush固件</a>。</p>

    <p>基于webpad旧版固件（对应官方固件 v2.19 版）的极限精简版。</p>

    <p>自带root，自带root管理，体积不大，非常干净。</p>

    <p>流畅度极佳。</p>
  </li>
  <li>
    <p><a href="https://www.znds.com/tv-1028090-1-1.html">潜龙固件</a>。</p>

    <p>论坛回复可见，于是我没测试¯_(ツ)_/¯。</p>
  </li>
</ul>

<p>挨个试用一遍后，最终选择了<a href="https://www.right.com.cn/forum/thread-315889-1-1.html">Rush固件</a>，不仅干净快速，系统体积小也让盒子有足够空间刷入Google框架。</p>

<h4 id="降级--刷机">降级 / 刷机</h4>

<p>详细流程请参阅 <a href="https://www.youtube.com/watch?v=EgvOxhO2odA">视频</a> / <a href="http://www.mtons.com/content/7926">帖子</a>。</p>

<p><a href="https://www.youtube.com/watch?v=EgvOxhO2odA">视频</a> / <a href="http://www.mtons.com/content/7926">帖子</a>里已经讲得非常细致，并且提供傻瓜工具打包下载，所以不再赘述。</p>

<p>只说注意事项：</p>

<ol>
  <li>准备一只有线鼠标，接入N1盒子<strong>最靠边的USB</strong>；</li>
  <li>准备一条<a href="https://www.jd.com/chanpin/562798.html">双公头USB数据线</a>，接入电脑与N1盒子<strong>HDMI接口旁的USB</strong>；</li>
  <li>刷机时<strong>最好</strong>将N1盒子用HDMI连接电视/显示器；</li>
  <li>刷机时<strong>务必</strong>用网线连接N1盒子与路由器。</li>
</ol>

<p>要是没有那奇葩的 <strong>双公头USB数据线</strong> 也不用担心。</p>

<p>——因为完全可以用<strong>普通数据线</strong>连接<strong>Windows平板</strong>进行刷机，就像我这样：</p>

<p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2pq6o1jj212w0pykjm.jpg" alt=""></p>

<p><del>这可是我忘记购买数据线后急中生智的解法。</del></p>

<p><strong><del>“黄油板真是伟大发明！”</del></strong></p>

<h4 id="google框架">Google框架</h4>

<p>如果你想刷入，请使用<a href="https://right.com.cn/forum/forum.php?mod=viewthread&amp;tid=338759">webpad固件</a>里提供的<a href="https://pan.baidu.com/s/1LNxx7CC0KajW-0OisRONRg">选装功能一键工具</a>（密码：5dx7）。</p>

<p><strong>个人不推荐刷入Google框架</strong>。</p>

<p>因为：</p>

<ul>
  <li>
    <p>刷入后需要<strong>手动去Google认证设备</strong>才能登录，非常麻烦。</p>

    <p>认证方法请参阅<a href="https://www.right.com.cn/forum/forum.php?mod=viewthread&amp;tid=323968">该贴</a>。</p>
  </li>
  <li>
    <p>由于固件本身基于标准Android7.1.2，刷入的Play商店自然是标准版，用遥控器操作异常蛋疼。</p>
  </li>
  <li>
    <p>商店内<strong>大堆应用不能安装</strong>，依然得自己手动下载。</p>

    <p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2qwu31yj20hq07kq3f.jpg" alt=""></p>
  </li>
  <li>
    <p>Google全家桶体积+后台感人，刷入后必然影响速度，虽然影响不大。</p>
  </li>
</ul>

<p><del>权衡之后，我选择了刷入。</del></p>

<p><del>因为我需要登入YouTube，这就毫无办法。</del></p>

<p>当然了，YouTube也有魔改后不需要Google框架就能登入的版本，比如<a href="https://smartyoutubetv.github.io/">Smart YouTube TV</a>。</p>

<p>然而这玩意精简过头，应用动画特效全部删光，用起来贼“卡”。</p>

<h4 id="换个launcher">换个Launcher</h4>

<p>无论刷入哪个固件，自带的Launcher要么简陋难看，要么国产乐色。</p>

<p>于是找了几个符合原生Android TV逻辑的Launcher：</p>

<ul>
  <li>
    <p><a href="https://play.google.com/store/apps/details?id=net.i.akihiro.halauncher">HALauncher</a></p>

    <p>优点：非常标准的启动器，自定义项目异常丰富，自带广告可在设置中关闭。</p>

    <p>缺点：自定义项目多到了繁杂，配置需要花些时间。</p>
  </li>
  <li>
    <p><a href="https://www.youtube.com/watch?v=4zLQmJT4lRk&amp;t=351s">5kong</a>修改的<a href="https://pan.baidu.com/s/1OkEY0PVDwj54rkiBiUtueA">ATVlauncher</a>（密码：wt5q）</p>

    <p>优点：同样的标准启动器，没有广告。</p>

    <p>缺点：几乎没有自定义，别说分组/隐藏应用，就连壁纸都没法修改。</p>
  </li>
</ul>

<p>因为懒，我用了第二个。</p>

<h1 id="遥控选择">遥控选择</h1>

<p>斐讯N1并不自带遥控器，所以得额外准备，选择有三。</p>

<h4 id="官方t1遥控器">官方T1遥控器</h4>

<p>斐讯的真・电视盒子T1所带的遥控器，据说能完美开关N1，并且配合<a href="http://www.yyfrom.com/cms/index.html">YYF固件</a>可以使用语音。</p>

<ul>
  <li>
    <p><strong>然而贵</strong>。</p>

    <p>一个遥控器在拼多多单价39起跳，已经能买半个N1盒子了。</p>
  </li>
  <li>
    <p><strong>并且丑</strong>。</p>

    <p>毕竟原本是搭配T1的遥控器，黑色菱角与N1那雪白机身简直两个画风。</p>
  </li>
</ul>

<h4 id="小米遥控器--第三方遥控器">小米遥控器 / 第三方遥控器</h4>

<p>老盒子自带一只，于是直接用上。</p>

<p><strong>长按“主页键”+“菜单键”即可配对</strong>。</p>

<p>使用上的小毛病有三个：</p>

<ol>
  <li>开机状态下按下遥控器的电源按钮，盒子会重启，而不是关机或休眠。</li>
  <li>盒子冷启动，进入桌面后需要等几秒让遥控器自己连上。</li>
  <li>基于官方固件 v2.19 版修改的第三方固件在初次配对时不会自动连接，需要插上鼠标进入原生Android设置，在蓝牙里进行手动选择。</li>
</ol>

<p>其它完美。</p>

<h4 id="sony电视遥控器">Sony电视遥控器</h4>

<p>如果你用的是Sony电视，会发现神tm Sony那遥控器<strong>不用配对</strong>就能直接控制盒子。</p>

<p>并且Sony遥控器能做到<strong>点一次关机按钮</strong>，就在关闭电视机的同时，<strong>休眠</strong>斐讯N1。</p>

<p>缺点当然还是有的：</p>

<ol>
  <li>可以休眠盒子但不能唤醒，需要用小米遥控器打开。</li>
  <li><del>按键手感差。</del></li>
</ol>

<p><strong>——最后，我用小米遥控器+Sony遥控器做到了最完美的遥控。</strong></p>

<ul>
  <li>小米遥控器负责唤醒N1和日常使用；</li>
  <li>Sony遥控器负责关闭电视机+休眠N1；</li>
</ul>

<p><strong>使用体验与手头的小米盒子无异，而现在</strong> <strong>休眠盒子+电视关机</strong> <strong>能用一只遥控器一键同时搞定，反而更加方便。</strong></p>

<p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2tqe5ghj212w0qeb2a.jpg" alt=""></p>

<p>把斐讯N1，斐讯电源，小米遥控器，以及小米HDMI线摆在一起。</p>

<p><strong><del>——这和谐得分明是一家人，堪称异父异母的亲兄弟。</del></strong></p>

<p>最后播放了一下NAS上的卡通片和YouTube 4K，鸟枪换炮，无比顺畅。</p>

<p>至此，N1盒子作为电视盒子的<strong>固件+软件+硬件</strong>全部搞定。</p>

<h1 id="一点遗憾">一点遗憾</h1>

<p>购买N1的一大目的就是为了<strong>千兆网口</strong>。</p>

<p><strong>——用来串流steam。</strong></p>

<p>然而我刷了三个固件，发现<a href="https://play.google.com/store/apps/details?id=com.valvesoftware.steamlink&amp;hl=ja">Steam Link</a>始终<strong>无法识别</strong>我的ds4手柄，无解，作罢。</p>

<p>好消息是：</p>

<ul>
  <li>遥控器可以控制游戏，几个按钮对应原本功能，被映射为“上下左右”和“菜单确定”。</li>
  <li>无线键鼠也可以控制游戏。</li>
</ul>

<p>打了一会儿<a href="https://www.orithegame.com/blind-forest/">《Ori and the Blind Forest》</a>，画面完美。</p>

<p>至于手柄可用性，只能等以后买了其它手柄再进一步测试了。</p>

<h1 id="尾巴">尾巴</h1>

<p>斐讯N1作为一款原本用来挖矿的“灵车”硬件，却凭借<strong>优秀性能+丰富接口+低廉价格</strong>，以电视盒子的身份迎来第二春。</p>

<p><strong>——即使现在全新货从70涨到了90，性价比也依然爆棚。</strong></p>

<p>如果你的老盒子需要升级，N1简直是不二之选。</p>

<p>因为300内你买不到比这更好的电视盒子，无论是性能，价格，接口，还是外观设计。</p>

<p>而斐讯官方也看到商机，神tm将库存N1刷上盒子系统准备以<a href="https://mall.phicomm.com/item-347.html">实价299再次开卖</a> <strong>（能否刷机未知，慎入）</strong>。</p>

<p><img src="/wp-content/uploads/2026/08/741f9461ly1g0u2vrspowj20w908oac9.jpg" alt=""></p>

<p>足见N1在电视盒子领域的优秀。</p>

<p><strong>——而优秀不止于此。</strong></p>

<p><strong>随着网友<a href="https://www.right.com.cn/forum/forum.php?mod=viewthread&amp;tid=428599"><del>瞎几把</del>折腾</a>，N1的可刷固件早就不再局限于Android：</strong></p>

<ul>
  <li>刷<a href="https://www.right.com.cn/forum/thread-335609-1-1.html">Armbian</a>做<a href="https://www.right.com.cn/FORUM/forum.php?mod=viewthread&amp;tid=342164">NAS</a>和<a href="https://www.right.com.cn/FORUM/forum.php?mod=viewthread&amp;tid=351028">媒体中心</a>；</li>
  <li>刷<a href="https://right.com.cn/forum/forum.php?mod=viewthread&amp;tid=330503">Volumio</a>搭音乐服务；</li>
  <li>刷lakka/<a href="https://www.right.com.cn/forum/forum.php?mod=viewthread&amp;tid=331363">sx05re</a>做游戏主机；</li>
  <li>刷<a href="https://www.right.com.cn/forum/thread-468983-1-1.html">Openwrt</a>当路由；</li>
  <li>还有<a href="https://www.right.com.cn/forum/thread-324404-1-1.html">固件</a>直接当纯粹的下载机。</li>
</ul>

<p><del>当初上了灵车的乘客为了不让自己的钱打水漂</del> ，俨然是把N1玩成了<a href="https://www.raspberrypi.org/products/">树莓派</a>。</p>

<p>而N1的硬件规格和丰富接口，也提供了“被人玩坏”的基础。</p>

<p>未来某天我恐怕会再次购入N1，不过那时就不是用做电视盒子了。</p>

<p>毕竟……</p>

<p>这倒霉玩意除了缺个GPIO，同样能吊锤树莓派3B，<strong>无论性能还是价格</strong>。</p>

<p><strong>一名“跨界选手”愣是在两个领域打出“全场最佳”。</strong></p>

<p>套用<a href="https://about.me/takedakinji">小竹公主</a>金句，这就是——</p>

<blockquote>
  <p>“真TM牛逼疯了！”</p>
