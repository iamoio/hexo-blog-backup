0px;text-transform: none;word-spacing: 0px;white-space: normal"><span>三步跑起来(真能复现)</span></h2><p><b><span>Step 1 · 克隆安装</span></b></p>

```
git clone https://github.com/firecrawl/open-lovable.git
cd open-lovable
pnpm install   # 或 npm install / yarn install
```

<p><b><span>Step 2 · 配置 .env.local</span></b></p>

```
# 必填: Firecrawl key(注册即送免费额度)
FIRECRAWL_API_KEY=your_firecrawl_api_key

# 选一家 LLM: 以下任选
GEMINI_API_KEY=...        # 或 ANTHROPIC / OPENAI / GROQ

# 沙箱二选一(默认 Vercel)
SANDBOX_PROVIDER=vercel    # 或 e2b
```

<p><b><span>Step 3 · 开干</span></b></p>

```
pnpm dev   # 打开 http://localhost:3000
# 贴个网址, 看它现场给你造一个 React 应用
```
