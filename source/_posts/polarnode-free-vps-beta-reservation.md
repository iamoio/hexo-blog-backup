<p style="margin:0 0 8px;font-weight:bold;color:#7f1d1d;">最需要当心的一条</p>
<p style="margin:0;font-size:15px;line-height:1.8;color:#7f1d1d;">官方规则的用词是「连续七日未开机将自动<strong>销毁</strong>」——注意是销毁，不是停机保留。机器一销毁，里面没备份的数据就没了。打算长期用的，务必自己做好异地备份，或者设个定时提醒，隔几天登一次。</p>

<ul>
<li><strong>一邮箱一 IP，只能约一次：</strong>禁止用多个邮箱重复预约，官方明确一经查证将<strong>取消该用户的所有预约及赠送资格</strong>。别用家里宽带 + 手机流量各来一发，IP 是会被记的。</li>

<li><strong>公测时间未定：</strong>官方只说"公测时间另行通知"，也就是说没人知道内测期会持续多久。</li>
<li><strong>型号可能调整：</strong>官方称"更多型号陆续开放"，同时带宽与不限流量方案"具体以内测开启时对应型号说明为准"——最终以领取页的实际标注为准。</li>

<h2>八、开机后建议先做的几件事</h2>
<p>不管最后拿到哪个节点，开机第一件事都不是装环境，而是先把机器锁好。下面这套是最基础的一套动作，照着跑一遍能挡掉绝大多数扫端口的自动化脚本。</p>

```bash
# 1. 先更新系统
apt update && apt upgrade -y

# 2. 新建一个普通用户并给 sudo（别一直用 root）
adduser myuser && usermod -aG sudo myuser

# 3. 装密钥登录，禁用密码登录与 root 远程登录
mkdir -p /home/myuser/.ssh && echo "你的公钥" > /home/myuser/.ssh/authorized_keys
chmod 700 /home/myuser/.ssh && chmod 600 /home/myuser/.ssh/authorized_keys
sed -i 's/^#?PermitRootLogin.*/PermitRootLogin no/' /etc/ssh/sshd_config
sed -i 's/^#?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart ssh

# 4. 开防火墙，只放行需要的端口
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp && ufw enable
```
