<p>想做一个自己的微信小程序，却被满屏的代码吓退？其实不用会编程。腾讯云推出的 <strong>WorkBuddy</strong> 是一款 AI 开发助手，你只要用大白话把想法说出来，它就能自动生成小程序的完整代码，从注册账号到正式上线一气呵成。</p>

<p>本文结合腾讯云开发者社区多篇实战教程，为你整理出一份<strong>保姆级全流程图文指南</strong>：准备什么、选哪种开发方式、怎么描述需求、生成后如何预览调试、最后怎样过审上线。建议收藏，照着做就行 👍</p>

<h2>一、为什么选这款 AI 助手？（3 个核心优势）</h2>
<ul>
<li><strong>自然语言生成</strong>：用大白话描述需求，AI 自动写出 WXML / WXSS / JS 代码，无需深厚编程基础。</li>
<li><strong>多端多框架支持</strong>：支持微信原生框架，也兼容 TDesign、WeUI 等主流组件库；进阶还能接云开发。</li>
<li><strong>实时预览 + 一键导出</strong>：内置模拟器边改边看，生成后可一键下载完整项目代码。</li>
</ul>
<blockquote>实测：一个含 4 个页面的天气小程序，约 2000 行代码，从描述需求到导出只用了 <strong>约 5 分钟</strong>。</blockquote>

<h2>二、开工前的准备（两张"入场券"）</h2>

<h3>2.1 注册微信小程序账号</h3>
<ol>
<li>打开微信公众平台小程序注册页，点「立即注册」→ 选择「小程序」。</li>
<li>用一个<strong>未绑定过公众号 / 小程序</strong>的邮箱激活账号。</li>
<li>在「开发管理 → 开发设置」里复制 <strong>AppID</strong>（格式如 <code>wx1234567890abcdef</code>），这是小程序的唯一标识。</li>
<li>如需后端，在同一页面获取 <strong>AppSecret</strong>（仅显示一次，务必保存）；并提前添加服务器域名（需 HTTPS）。</li>
</ol>
<p>⚠️ 暂时没有 AppID 也能用微信开发者工具的「测试号」开发，但<strong>上传和上线必须有正式 AppID</strong>。</p>

<h3>2.2 安装工具</h3>
<table>
<thead><tr><th>软件</th><th>用途</th><th>是否必须</th></tr></thead>
<tbody>
<tr><td>微信开发者工具</td><td>写代码 + 预览 + 真机调试 + 上传代码（你的 IDE）</td><td>✅ 必须</td></tr>
<tr><td>AI 开发助手</td><td>用自然语言生成小程序代码。网页端或桌面版均可</td><td>✅ 必须</td></tr>
<tr><td>Git</td><td>版本管理，方便回滚</td><td>⭐ 推荐</td></tr>
</tbody>
</table>
<p>原生框架不需要 HBuilderX，也不需要 Node.js 编译——微信开发者工具一个就够。</p>

<h3>2.3 环境检查清单</h3>
<ul>
<li>☐ 腾讯云账号已注册并完成实名认证</li>
<li>☐ 已获取微信小程序 AppID</li>
<li>☐ 电脑已安装微信开发者工具，并用微信扫码登录</li>
<li>☐ 微信开发者工具：设置 → 安全设置 → 开启服务端口</li>
<li>☐ 本地设置 → 勾选「不校验合法域名」（仅开发阶段）</li>
</ul>

<h2>三、三种开发方式，选你顺手的</h2>

<h3>方式 A：Craft 模式（桌面版，最推荐新手）</h3>
<p>打开桌面版助手，切换到 <strong>Craft 模式</strong>——这个模式下 AI 会<strong>真正动手创建和修改文件</strong>，而不是只给你代码片段。直接把想法告诉它：</p>

```
帮我初始化一个微信原生小程序项目，项目名"喵管家"，放在当前目录下。
然后一步步帮我搭建：首页列表、详情页、关于页，采用简约蓝色主题。
```

<p>几分钟后，一个包含 <code>app.json</code> 全局配置、各页面 <code>js/wxml/wxss/json</code> 和完整目录结构的项目就生成好了。你只需要把需求说清楚：有几页、每页干什么、什么风格，它就不会瞎编，生成出来直接能用。</p>

<h3>方式 B：安装"小程序开发助手"技能（技能市场）</h3>
<p>这类 AI 工具的能力通常通过「技能（Skills）」扩展。在对话框或左侧菜单找到<strong>技能市场</strong>，搜索「小程序」或「mini-program」，安装对应助手；需要云端数据库和自动化部署，可再装「云开发」技能。如果一时找不到，直接发「帮我安装小程序开发技能」，工具会自动搜索并引导你安装。</p>

<h3>方式 C：云开发（进阶 / 需要后端）</h3>
<p>如果你的小程序要存数据、调接口，用云开发最省心。在对话里启用云开发能力，然后一路对话：创建项目、建集合、写云函数取数据、部署、在首页调用显示即可，连服务器都不用买。</p>

<h2>四、写好需求描述（最关键的一步）</h2>
<p>描述越详细，一次成型率越高；含糊其辞就要反复改。套用下面的通用模板：</p>

```
[类型] 一个[功能名]小程序
[功能] 包含[功能点1]、[功能点2]、[功能点3]
[设计] 采用[颜色/风格]主题
[交互] 支持[特殊交互需求]
[存储] 使用微信云数据库（可选）
```

<table>
<thead><tr><th>描述质量</th><th>示例</th><th>生成效果</th></tr></thead>
<tbody>
<tr><td>❌ 模糊</td><td>"做个天气 app"</td><td>需要多次调整</td></tr>
<tr><td>✅ 详细</td><td>"一个天气查询小程序，含城市搜索、7天预报、洗车指数，蓝色渐变主题"</td><td>一次成型</td></tr>
</tbody>
</table>
<p>建议每次都包含：<strong>功能需求、页面结构、交互逻辑、设计风格</strong> 四要素。例如：「一个记账小程序，含支出记录、分类统计、月度报表，简约绿色主题，支持导出 Excel」。</p>

<h2>五、AI 生成代码 &amp; 项目结构</h2>
<p>收到指令后，AI 会自动干活：创建目录、写页面代码、配置云数据库、生成云函数，整个过程约 <strong>5–10 分钟</strong>（视复杂度）。典型原生项目结构如下：</p>

```
miniprogram-demo/
├── app.js              # 全局逻辑
├── app.json            # 全局配置（页面路由、窗口样式）
├── app.wxss            # 全局样式
├── project.config.json # 项目配置
├── pages/
│   ├── index/          # 首页
│   │   ├── index.js
│   │   ├── index.wxml
│   │   ├── index.wxss
│   │   └── index.json
│   └── detail/         # 详情页
└── cloudfunctions/     # 云函数（云开发时才有）
    └── getQuote/
```

<h2>六、导入微信开发者工具预览</h2>
<ol>
<li>打开微信开发者工具，点「导入项目」。</li>
<li>目录选<strong>包含 <code>app.json</code> 的那个文件夹</strong>（才是项目根目录）。</li>
<li>AppID 填刚才复制的 <code>wx</code> 开头那串，或用测试号。</li>
<li>点「编译」，左侧模拟器亮起来的那一刻——你自己的小程序真的跑起来了。</li>
</ol>

<h2>七、调试与修改（报错直接丢给 AI）</h2>
<p>跑起来发现按钮没反应、页面白屏？不用自己排查。直接把报错复制给 AI：</p>
<blockquote>「导入后 Console 报了这个错：（粘贴报错信息），帮我定位要改哪些文件。」</blockquote>
<p>它会立刻帮你分析并修复对应文件。满意后还能继续对话做增量修改，比如「把首页主色改成 #4A90E2」「加一个分享给好友的按钮」。</p>

<h2>八、提交审核与上线</h2>
<p>改满意后，在微信开发者工具点「上传」，然后进微信公众平台「版本管理」提交审核。</p>
<h3>提交前检查清单</h3>
<table>
<thead><tr><th>序号</th><th>检查项</th><th>说明</th></tr></thead>
<tbody>
<tr><td>1</td><td>完成实名认证</td><td>账号主体必须实名</td></tr>
<tr><td>2</td><td>配置服务器域名</td><td>业务域名需 HTTPS（云开发可省略）</td></tr>
<tr><td>3</td><td>测试所有功能</td><td>确保无明显 bug</td></tr>
<tr><td>4</td><td>准备审核资料</td><td>logo、简介、类目资质</td></tr>
<tr><td>5</td><td>隐私协议</td><td>填写用户隐私保护指引</td></tr>
</tbody>
</table>
<p>发布流程：<strong>版本管理 → 提交审核 → 等待通过（通常 1–7 天）</strong>。资料不全或类目不符是最常见被拒原因，提前备齐能省一轮来回。</p>
